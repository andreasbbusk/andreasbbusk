# Andreas Busk Mikkelsen

I’m a web developer based in Aarhus, Denmark. I build fast, type-safe web applications. Currently, I'm studying Web Development and working at Engredo A/S. 

My work focuses on the intersection of complex data, business logic, and user interfaces. I care deeply about developer experience and end-to-end type safety. For me, good architecture is about writing code that is predictable, maintaining strict boundaries between services, and delivering interfaces that feel instantaneous to the user.

Most of my daily work happens within the React and TypeScript ecosystem, heavily utilizing Next.js to bridge the gap between the server and the client.

### What I'm building

*   **Engredo Hub**: A modular operations and logistics system built from scratch in a Next.js monorepo. It leverages tRPC, Zod, and Prisma to ensure strict type-safety across the entire stack. *(Private repository)*
*   **[Rank Tracker](#)**: A frontend data-visualization tool integrated with the Google Search Console API to monitor SEO performance over time.
*   **[Verto](#)**: A flashcards app for focused, keyboard-first study sessions.
*   **[Goldilox Paradox](#)**: Single-page WebGL scrollytelling through Earth, Venus, and Mars.
*   **[Portfolio](https://andreasbusk.dk)**: My personal site and playground for testing new web patterns, built with Next.js and Tailwind CSS.
